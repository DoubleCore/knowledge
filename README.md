## Repository Context

This repository was **initialized from the [`oldwinter/knowledge-garden`](https://github.com/oldwinter/knowledge-garden) template**.

The template, publishing framework, and original example content belong to the upstream project and its contributors. This repository is my working copy for experimenting with a personal knowledge system; it should not be interpreted as an original implementation of the knowledge-garden framework.

## What I Use It For

- research notes and paper-reading context;
- AI and software-engineering knowledge;
- project documentation and reusable workflows;
- linked notes and long-term knowledge accumulation;
- experimenting with a public/private digital-garden workflow.

## Working Model

```text
Capture
   ↓
Connect
   ↓
Refine
   ↓
Reuse in Projects
   ↓
Review & Update
```

The goal is not to collect as many notes as possible. The goal is to make previous learning **retrievable and reusable when solving the next problem**.

## Tooling

This workspace is designed around Markdown and backlink-oriented note tools such as Obsidian. Because it originates from `knowledge-garden`, parts of the directory structure and publishing setup may still reflect the upstream template.

## Portfolio Role

This repository represents the **knowledge layer** of my Professional AI Player training system:

> Projects produce experience. Notes turn that experience into reusable capability.
